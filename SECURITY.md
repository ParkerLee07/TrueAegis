# Security Policy

## Supported Versions

TrueAegis is currently in beta. Security fixes will target the latest public version.

| Version | Supported |
|---|---|
| v1.1-beta | Yes |
| Older development builds | No |

## Reporting Security Issues

If you discover a security issue in TrueAegis, please do not publicly disclose it immediately.

Recommended report contents:

- affected component
- reproduction steps
- impact
- suggested fix, if known
- logs or screenshots, if useful

## Scope

Security reports may include:

- unsafe command execution
- insecure file handling
- local web dashboard issues
- dependency risks
- incorrect trust assumptions
- exposure of sensitive files

## Important Notes

TrueAegis runs local scans and local analysis. Users should avoid committing:

- scan results
- reports containing private IPs
- real customer data
- credentials
- internal hostnames
- sensitive screenshots
