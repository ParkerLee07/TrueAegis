# Ethical Use Policy

TrueAegis and NetSniper are intended for authorized security work only.

Acceptable uses include:

- scanning networks you own
- scanning networks where you have written permission
- internal exposure review
- lab environments
- defensive security training
- vulnerability management support
- security research in controlled environments

Do not use this project to:

- scan third-party networks without authorization
- access systems without permission
- bypass authentication
- exploit systems
- disrupt services
- collect sensitive data from systems you do not own or administer

Users are responsible for complying with all applicable laws, policies, and rules of engagement.

If you are unsure whether your use is authorized, do not run the tool.
